# keep-meaning-japanese

**意味を変えずに、文章はもっと自然に。**

具体的な情報や書き手の声を保ちながら、自然で明瞭な日本語を書くためのSkillです。新しい文章の作成にも、既存原稿の推敲にも使えます。

読みやすくするためなら、語彙や語順、文の分け方、段落構成まで柔軟に変更します。ただし、入力にない事実を足したり、主張を強めたりはしません。

## こんな文章に向いています

- ビジネス文書、社内文書、メール
- 記事、ブログ、解説文
- 技術文書、業務手順、調査レポート
- 履歴書、職務経歴書、応募書類
- 語調や書き手らしさを残したい文章

文章を短くすることだけを目的にせず、読者、用途、文体に合わせて、必要な情報が自然に伝わる形へ整えます。

## 設計思想

> **表現の自由度は高く、意味の自由度は低い。**

表面的な言い換えにとどまらず、読みやすさに必要なら文章の構造も変えます。一方で、次の要素は原文に忠実に保ちます。

- 事実、数値、主体、対象
- 条件、否定、時系列、因果関係
- 確信の度合い、主張の範囲と強さ
- 書き手の立場、関与の度合い、語調

## Before / After

たとえば、抽象的で硬さのある説明文を推敲すると、次のようになります。

### Before

> 現代社会において、テクノロジーの進化は私たちの生活や働き方に大きな変化をもたらしています。一方で、単に新しい技術を導入するだけでは、十分な効果を得ることはできません。重要なのは、目的や課題を明確にしたうえで、人とテクノロジーそれぞれの強みを活かすことです。今後は、変化を柔軟に受け入れながら、持続可能でより良い社会の実現を目指していくことが求められるでしょう。

### After

> テクノロジーの進化により、私たちの暮らしや働き方は大きく変わっています。ただ、新しい技術を導入するだけでは、十分な効果は得られません。目的と課題を明確にし、人とテクノロジーの強みをそれぞれ活かすことが重要です。これからは変化を柔軟に受け入れながら、持続可能でより良い社会を目指すことが求められるでしょう。

回りくどい表現を整理し、文と文のつながりを自然にしています。新しい事実は加えず、原文の論点と主張の強さを保っています。

## インストール

### Codex（ChatGPT）

ターミナルで次のコマンドを実行し、CodexのSkillディレクトリに配置します。

```bash
git clone https://github.com/yosukekurita-rgb/keep-meaning-japanese.git \
  ~/.agents/skills/keep-meaning-japanese
```

配置後、Codexへの依頼で `$keep-meaning-japanese` を指定します。

### Claude・Notion AIなど

次のどちらかの方法で取り込み、文章作成や推敲の依頼時にこのSkillを使うよう指定します。

- GitHubからダウンロードしたZIPファイルを読み込ませる
- このリポジトリのURLを渡して内容を読み込ませる

## 基本的な使い方

Skill名、文章の用途、希望する文体、対象の文章を伝えます。細かな条件がなければ、次の形ですぐに試せます。

```text
$keep-meaning-japanese を使って、以下の文章を社内向けに自然で明瞭な日本語へ推敲してください。
意味、数値、主体、条件、主張の強さは変えないでください。

（対象の文章）
```

新しく文章を作る場合は、材料と読者、目的を伝えます。

```text
$keep-meaning-japanese を使って、以下の材料から顧客向けの案内文を作成してください。
丁寧で簡潔な文体にしてください。

（文章に含めたい材料）
```
